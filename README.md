# StyleShop — Bootstrap 5 Ecommerce Landing Page 🛍️

A clean, responsive ecommerce landing page built with **Bootstrap 5** and a small amount of custom CSS/JS. This repository contains a demo storefront UI (hero, categories, featured products, newsletter, testimonials, and a demo cart interaction).

## Features ✅
- Responsive layout using Bootstrap 5
- Navbar with search and cart icon (live counter)
- Hero section with CTA buttons
- Category cards and featured product grid
- Simple add-to-cart demo using JS + toast notifications
- Custom styles in `styles.css` and Bootstrap Icons for visual polish

## Files 📁
- `index.html` — main landing page
- `styles.css` — custom page styles
- `media/` — images used by the page (replace with your own images)

## Quick Preview 🔧
> Note: For full functionality (fetching files, JS features), open the page through a local server instead of `file://`.

Run a simple local server from the project folder:

- Python 3:

  ```bash
  python -m http.server 8000
  # then open http://localhost:8000
  ```

- Node (http-server):

  ```bash
  npx http-server -p 8000
  # then open http://localhost:8000
  ```

Or use the "Live Server" extension in VS Code.
